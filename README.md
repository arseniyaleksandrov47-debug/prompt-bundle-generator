# Prompt Bundle Generator

Система генерации промптов через Groq API с параллелизмом, ИИ-анализом качества и сборкой бандлов для маркетплейсов.

## Архитектура

### Директории

- `/src` — оркестратор (скрипты: analyze / generate / evaluate / patch / package)
- `/datasets` — входные списки тем/промптов в TSV/текст, read-only
- `/profiles` — ключи Groq, лимиты RPS/TPM, размеры батчей, конфиг площадок
- `/golden` — 30–50 эталонных кейсов для быстрой смок-проверки
- `/runs/{ts}_{hash}/` — всё, что создаёт пайплайн (артефакты, логи)
- `/cache` — кэш LLM и Bloom-фильтры
- `/tmp` — временные файлы (чистятся на старте)

### Формат данных (строки/TSV, без JSON)

Одна строка = один юнит/промпт:
```
id \t prompt \t meta \t out \t score \t flags
```

- `meta` — свободный текст (например: «язык=ru; канал=email; длина=70»)
- Табуляции/переводы внутри полей экранируются как `\t/\n`
- Шардирование: вход режется на `shard_0000.tsv` … по `hash(id)` → детерминированный параллелизм

## Пайплайн

1. **Intake** — бриф темы + список промптов/заданий (TSV)
2. **Topic Profiling** — ИИ читает бриф → пишет ТЗ темы в `/runs/.../topic.md`
3. **Generate** — параллельно через Groq, результат в поле `out`
4. **Dedup** — pre/post дедупликация
5. **Evaluate** — эвристики + synth-checks, запись `score/flags`
6. **Patch** — точечные правки по флагам
7. **Re-Evaluate** — повтор проверок
8. **Package** — сборка бандла для маркетплейсов

## Производительность

- Целевая скорость: ≈1 мин/1000 промптов
- Параллелизм = количество ключей Groq
- Batch size 32–128, keep-alive, без стриминга
- Кэш-хит ≥60–80% на доводках

## Качество

- Стандарт: 9.5–9.9/10 для любой темы
- Условия релиза: ≥98% строк имеют score ≥ 9.5 и flags == ""
- Обязательные 7 блоков в README для любой темы

## Установка

```bash
pip install -r requirements.txt
```

## Быстрый старт

1. Настройте API ключи Groq в `/profiles/keys.tsv`
2. Подготовьте входные данные в `/datasets/`
3. Запустите пайплайн:

```bash
python src/main.py --topic "ваша тема" --input datasets/prompts.tsv
```

## Структура бандла

Создаётся в `/runs/{ts}_{hash}/bundle/`:
- `listing.md` — описание для маркетплейсов
- `README.md` — инструкции (7 обязательных блоков)
- `preview_top_examples.txt` — лучшие примеры
- `ready/` — ≥120 готовых артефактов
- `checks.md` — статус проверок качества

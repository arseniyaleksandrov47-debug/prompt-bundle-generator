# 🚀 Quick Start Guide

## Самый простой способ запуска

### 1. Настройте параметры
Отредактируйте файл `profiles/project_config.yaml`:

```yaml
project:
  topic: "Ваша тема здесь"           # ← Измените тему
  target_count: 1000                 # ← Количество промптов
  batch_size: 64                     # ← Размер батча (32/64/128/256)
```

### 2. Запустите проект
```bash
python run_project.py
```

Всё! Система автоматически:
- Загрузит настройки из YAML
- Запустит весь пайплайн
- Создаст готовый бандл в папке `runs/`

## Настройка batch_size

**Размер батча влияет на:**
- **32** - медленнее, меньше памяти
- **64** - оптимально для большинства случаев  
- **128** - быстрее, больше памяти
- **256** - максимальная скорость, много памяти

## Альтернативный способ (CLI)

Если нужен полный контроль:
```bash
python src/cli.py generate \
  --topic "Ваша тема" \
  --input datasets/sample_prompts.tsv \
  --batch-size 128 \
  --target-count 2000
```

## Dry Run (тестирование)

Для тестирования без API вызовов:
```yaml
processing:
  dry_run: true  # ← Включить тестовый режим
```

## Файлы конфигурации

- `profiles/project_config.yaml` - основные параметры проекта
- `profiles/config.yaml` - продвинутые настройки системы
- `profiles/keys.tsv` - API ключи Groq
